Model Tier Reference — Light / Medium / Heavy

EdgeRunner organizes its military-tuned models into three tiers by parameter count, hardware envelope, and operational role. Smaller is not lesser. Each tier is optimized for the workload it serves — a Light-tier model running on a handheld is more useful to a forward operator than a frontier model that cannot run there at all. Tier selection is a deployment choice, not a quality ladder.

Tier Operational Role Model Range Hardware Class Optimized For Typical Workloads
Light Tier 1 Immediate Operator AI Forward-deployed individual user; offline by default. 1B – 4B
parameters
 Handheld, tablet, laptop, TAK device. 8 GB VRAM minimum. Speed, low power draw, disconnected ops survivability.
Inherent Advantage Sub-second time-to-first-token. Runs on government-furnished hardware already in the operator's hand. No thermal envelope problem. No network dependency.
Reporting, translation, entity extraction, voice assistant, chain-of-thought formatting, structured-data capture at the point of work.
Medium Tier 2 Tactical Mission Assistant Small-team and platform-level operations; intermittent connectivity tolerated. 7B – 26B
parameters
 Rugged workstation, CANES afloat node, vehicle-mounted compute. 16 GB VRAM recommended. Multi-step reasoning and domain-specific workflows at the edge.
Inherent Advantage GPT-class task accuracy without ceding data to commercial cloud. Fits inside a tactical power and bandwidth budget. Demonstrated GPT-5 task parity at this tier (Paper 2 — EV-031).
ISR fusion, technical-manual Q&A, planning support, mission coordination, MOS/AFSC-specialized assistants via LoRA adapters.
Heavy Tier 3 Mission Cell / Edge AI Server Shared inference for multiple operators; theater or installation node. 70B – 400B+
parameters
 Edge AI server, shipboard compute node, fixed-site rack. Multi-GPU. Shared inference, deep analysis, model adaptation, on-prem fine-tuning.
Inherent Advantage Frontier-class capability inside the security boundary. Centralized fine-tuning and LoRA training closer to the data. EdgeRunner can retrain any open-weight model up to and beyond 400B parameters under contract; 120B currently in development.
Multi-user analysis, model adaptation per command, LoRA training pipelines, knowledge synthesis across large doctrinal corpora.
Why Tiering Matters — A Specialization Argument, Not a Quality Ladder
A 4B model on a handheld delivers an answer in the seconds an operator actually has. A 400B model in a CONUS data center cannot. The right model is the one that runs where the decision is made, sized to the hardware that survives in that environment. EdgeRunner sizes each tier for its operational role: Light for latency and offline survivability; Medium for reasoning under a tactical power budget; Heavy for shared inference and on-prem training inside the security boundary. Buying down the tier ladder is buying toward the warfighter — not away from frontier capability.
