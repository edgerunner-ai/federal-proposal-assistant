# EdgeRunner AI — Brand Palette Reference

Source: www.edgerunnerai.com (extracted March 2026)

## Logo Asset
- **Master logo file:** `my-company/branding/edgerunner-logo.png` — use across all proposal templates and presentation slides. Place on white tile when overlaid on red header bars to preserve contrast.

## Slide Variant — Darker Red (for dense/dark slides)
- **Slide Brand Red:** `#C8102E` (darker variant of `#ee2929`, used on the company-overview slide and any dark-background dense layouts where #ee2929 reads as too bright). Tints derived as `rgba(200,16,46, …)`.

## Primary Colors
| Name | Hex | Use |
|------|-----|-----|
| Brand Red | `#ee2929` | Primary accent — titles, pills, badges, hero elements, glow effects |
| Dark Red | `#d4080e` | Hover states, darker accents |
| Near-Black | `#191c20` | Canvas/body backgrounds |
| Dark Grey | `#393939` | Borders, dividers, secondary structure |
| Medium Grey | `#9f9f9f` | Secondary text, subtitles, captions |
| Light Grey | `#c8c8c8` | Body text, descriptions |
| White | `#ffffff` | Headings, primary labels |

## Tint Values
| Name | Value | Use |
|------|-------|-----|
| Red tint (light) | `rgba(238,41,41,.08)` | Subtle background fills |
| Red tint (medium) | `rgba(238,41,41,.12)` | Column headers, callout backgrounds |
| Red tint (strong) | `rgba(238,41,41,.15)` | Hero tier fills |
| Red border | `rgba(238,41,41,.4)` | Commitment callouts, emphasis borders |
| White tint | `rgba(255,255,255,.03-.06)` | Subtle card/row backgrounds |

## Element Patterns
| Element | Treatment |
|---------|-----------|
| Title bars | White text, `border-bottom: 2px solid #ee2929` |
| Registry/badge pills | `#ee2929` fill, `#191c20` text |
| Commitment callouts | `rgba(238,41,41,.08)` fill, `#ee2929` border |
| Row accent bars | 4px wide, `#ee2929` |
| Glow/filter effects | `flood-color: #ee2929` |
| Boundary lines | `#4a4a4a` dashed |
| Boundary labels | `#222528` fill, `#4a4a4a` stroke, white text |
| Contract footers | `#111315` background, `#ee2929` text at 80% opacity |
