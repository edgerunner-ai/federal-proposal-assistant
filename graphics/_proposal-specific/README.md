# Proposal-Specific Graphics

One-off figures from specific proposals — kept for reference, not promoted to `_library/` because they're too narrowly scoped for direct reuse.

Use these as **starting points** when a new proposal needs something similar but customer-specific. Don't reuse them verbatim; the brand and structure are fine, but the labels reference specific programs (Vulcan/JATF, EXTIC, SOCPAC, Digital Guardian, etc.).

Each entry has `source.html` + `preview.png`. Check the canonical source path in CATALOG.md to find the originating proposal's data files if you need to fork rather than start fresh.
