Three-column hardware footprint: workstation/server tier → ruggedized edge → handheld/tactical. Calibrates evaluator expectations on what runs where, and grounds claims about "edge AI" in actual silicon.

**When to reuse:** any proposal that has to justify a hardware BOM, defend a "no GPU farm needed" claim, or scope deployment cost. Update SKU references when a new ruggedized platform is qualified.
