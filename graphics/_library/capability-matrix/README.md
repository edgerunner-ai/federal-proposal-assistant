Grid mapping solicitation requirements (rows) to EdgeRunner capabilities (columns) with cell-level evidence markers. Used as the visual companion to a compliance matrix when evaluators need to see coverage at a glance.

**When to reuse:** any proposal where a compliance/traceability story is a discriminator. Adjust row labels to the customer's requirement language verbatim — the matrix earns score by mirroring the evaluator's checklist.
