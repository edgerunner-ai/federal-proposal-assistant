Operator-in-the-loop pattern: shows the human decision points layered over the agentic workflow. Counter to "fully autonomous AI" framing — supports the "operator retains authority" win theme.

**When to reuse:** decision-support, intel-analyst, or any proposal where the customer's policy posture requires human oversight. Pair with discriminator language about audit trails and reversibility.
