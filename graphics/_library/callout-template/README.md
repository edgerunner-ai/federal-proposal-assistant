Reusable sidebar callout system — five visual variants (discriminator, proof point, commitment, definition, operational impact) sharing one design language. Lets prose sections drop in evidence and discriminator language as visual breaks without writing custom graphics each time.

**When to reuse:** any proposal that wants to surface discriminator language or proof points as visual elements alongside prose. See [_proposal-specific/extic-callouts](../../_proposal-specific/extic-callouts) for the five filled-in examples and the contact sheet.

**Five variants:**
- `cb-1-discriminator` — claim + supporting evidence (use for win themes)
- `cb-2-proof-point` — quantified outcome with source (TRL 8, contract refs)
- `cb-3-commitment` — promise to the customer (delivery, performance)
- `cb-4-definition` — term clarification (helps evaluators with jargon)
- `cb-5-operational-impact` — mission-outcome framing (so-what statement)
