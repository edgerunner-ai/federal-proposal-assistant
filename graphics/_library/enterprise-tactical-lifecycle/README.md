Specialized variant of lifecycle-loop emphasizing the **enterprise-to-tactical** direction: how an enterprise-trained model gets compressed, hardened, and pushed down to a tactical device. Used in the open-weight whitepaper to make the technical case for the program model.

**When to reuse:** when the proposal specifically argues for an enterprise→edge handoff (model pushdown). Prefer over generic lifecycle-loop when the customer cares about *where the training happens vs. where inference happens*.
